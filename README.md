A one-page visual summary of the world's news on Thursday 19 November 2026 — the Trump–Xi–Putin summit in Shenzhen, Anthropic's record IPO, the GTA VI launch, the Myanmar genocide verdict, Gaza, Cyclone Akvan, the Fed minutes, a record Van Gogh and the day's markets — drawn as a single 1024×1024 infographic. The HTML source (news.html) is rendered once to entry.png by render.mjs; main.ts copies that image to the output directory, byte for byte, every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
